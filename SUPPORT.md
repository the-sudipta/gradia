# Gradia Support

Choose the route that matches the request:

- **Bug:** open a [bug report](https://github.com/the-sudipta/gradia/issues/new?template=bug_report.yml)
  using fictional or redacted data.
- **Feature:** open a [feature proposal](https://github.com/the-sudipta/gradia/issues/new?template=feature_request.yml).
- **Security:** follow [SECURITY.md](SECURITY.md); never disclose a vulnerability publicly.
- **Commercial license:** follow [COMMERCIAL-LICENSING.md](COMMERCIAL-LICENSING.md).
- **Research, industrial PhD, or institutional pilot:** read the
  [research prospectus](docs/INDUSTRIAL_PHD_PROSPECTUS.md).
- **General contact:** use a private route on the maintainer’s
  [GitHub profile](https://github.com/the-sudipta).

Before asking for help, check the latest release, README, runbook, and existing
issues. Include the Gradia version, operating system, expected behavior, actual
behavior, and reproducible steps.

Do not attach real student IDs, names, marks, attendance, databases, backups, or
institutional spreadsheets.
